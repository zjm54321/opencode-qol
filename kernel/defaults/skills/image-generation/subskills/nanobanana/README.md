# Nano Banana references (adapted)

This directory adapts [generate-nanobanana](https://github.com/AntonioCardenas/generate-nanobanana) by Antonio Cárdenas / yeou.dev for OpenCode's native `experimental_image_generate` tool. It is a prompting reference, not an independently installed or published execution plugin.

Read `SKILL.md` for reference-image guidance and `models/` for model context. Follow the parent skill for runtime model selection and asynchronous completion. Standalone installation/update commands, Python SDK recipes, video generation and upstream output-folder conventions are not used here. Third-party `LICENSE`, `SOURCE` and provenance remain intact.
