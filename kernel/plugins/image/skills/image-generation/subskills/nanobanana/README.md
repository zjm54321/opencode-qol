# Nano Banana references (adapted)

This directory adapts [generate-nanobanana](https://github.com/AntonioCardenas/generate-nanobanana) by Antonio Cárdenas / yeou.dev for OpenCode's compiled-in `image_gen_nano` tool. It is not an independently installed or published package.

Read `SKILL.md` for the local tool workflow and `models/` for model-selection guidance. Standalone installation/update commands, Python SDK recipes, video generation and upstream output-folder conventions are not used here. Third-party `LICENSE`, `SOURCE` and provenance remain intact.
